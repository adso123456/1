## 对话生成契约

明确的报表指令由固定意图解析器拦截，不进入普通 Vanna SQL 生成：

```text
生成2025年7月28日水质日报
生成2025年7月28日水质日报，只看氨氮和总磷，近5日
生成2025年7月水质月报
```

未写指标时沿用各站点真实配置；写明指标时只选择数据库配置中同名指标。指定统一频次时必须同时写明指标，且频次必须存在于真实站点配置。对话返回确定性摘要、在线预览链接和 PDF 下载链接。

## 版式修正

参考 PDF 仅作为信息结构和视觉风格依据。实现已修正参考文件中的跨页表头缺失、窄列逐字断行、表格行被分页切断、页边距和尾页留白不稳定问题。正式 PDF 使用 A4 纵向、长表自动分页、每页重复表头、整行不拆分和系统中文字体。

## 快照与结构化交互契约

- 周期不明确的日报/月报请求返回 `report_config`：报告类型、默认日期或月份、日报回看天数、可用指标及频次、当前选择、固定数据源和缺失字段。
- 周期明确的请求返回 `report_result`：`report_id`、报告类型、标题、周期、指标、日报回看天数、频次、数据源、预览地址、下载地址和状态。
- 月报周期严格为一个自然月；除不显示日报回看天数外，月报与日报使用相同的指标多选、真实频次和参数校验。
- 月报正文按正式样例固定为“监测情况”和“各监测点位情况”两节；表1只列当月实际有传输数据的普通水质自动站，表2列全部普通水质自动站并保留跨页重复表头。
- 报表仅从对话进入；侧栏不提供独立“日报月报”导航。
- 每次生成将确定性报告 JSON 保存为 Git 忽略的不可变快照，PDF 使用同一 `report_id` 物理文件；预览和下载不重新查询数据库。
- 不同参数并发生成得到不同 `report_id`，相同内容可安全复用同一摘要；快照和 PDF 使用临时文件、原子替换、并发锁与安全路径校验。
- 指标筛选只接受真实配置名称和已确认安全别名；完全未知或部分未知均返回配置卡和明确错误，不生成报告。
